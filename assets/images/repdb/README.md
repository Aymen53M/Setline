# Setline exercise illustrations

This folder contains the RepDB free-tier exercise start/finish illustrations and highlighted muscle diagrams used by Setline. The matching table and static Metro imports are generated by `scripts/download-exercise-art.mjs`.

RepDB requires visible attribution in the app. Exercise detail screens show a link reading “Exercise illustrations and muscle maps by RepDB” beneath the muscle diagrams.

The images are bundled locally so the exercise guide still works when a gym has poor reception. Do not use or derive these assets with generative AI. The full dataset terms and required attribution text are in [LICENSE-DATA.md](LICENSE-DATA.md) and [ATTRIBUTION.md](ATTRIBUTION.md).

The chest-press video is a separate Centers for Disease Control and Prevention video, available in the public domain: [Wikimedia Commons source](https://commons.wikimedia.org/wiki/File:Muscle_Strengthening_at_the_Gym_-_Chest_Press.webm). It streams only when opened and is credited in the app.
